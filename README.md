## 📌 About The Project

**PHISHAWARE** is a cybersecurity awareness and phishing detection tool designed to help users identify malicious URLs and understand how phishing attacks work.

The project combines:

* 🔍 **Phishing URL Detection**
* 🎭 **Phishing Demonstration Simulation**
* 🛡️ **Cybersecurity Awareness**
* 🌐 **Safe Browsing Education**

PHISHAWARE analyzes suspicious links using multiple detection techniques such as:

* HTTPS verification
* Suspicious keyword detection
* Domain analysis
* URL structure validation
* Blacklist matching

The project is built using **HTML, CSS, and JavaScript** with a clean and interactive user interface.

---

# ✨ Features

## 🔎 URL Detection System

* Detects suspicious and phishing URLs
* Checks secure HTTPS protocol
* Identifies fake or misleading domains
* Highlights suspicious keywords in URLs
* Provides instant detection results

## 🎭 Phishing Demonstration Module

* Simulates phishing attack scenarios safely
* Educates users about fake login pages
* Demonstrates credential stealing techniques
* Improves cybersecurity awareness

# 🧠 How It Works

## URL Detection Process

1. User enters a URL
2. JavaScript analyzes the URL
3. Security checks are performed:

   * HTTPS check
   * Suspicious keywords
   * Fake domain patterns
   * URL length & structure
4. Detection result is displayed
